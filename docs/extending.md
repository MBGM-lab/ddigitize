# Extending a Path

To append more anchor points to an already-fitted path without discarding existing segments:

1. Click the **+** button next to the path name in the sidebar. The button label changes
   to **Extending…** and turns orange.
2. Click new anchor points on the canvas. They are added after the last existing point.
3. Click **Smooth Curves** or **Straight Lines** to fit the new portion. Only the
   extension is re-fitted; all existing segments and any manually adjusted handles are
   preserved exactly.
4. Clicking the **Extending…** button again cancels extend mode without fitting.

# Keyboard Shortcuts

On macOS, substitute `Cmd` for `Ctrl` throughout.

| Shortcut | Action |
|----------|--------|
| Left-click (canvas) | Place anchor point |
| `Alt+Click` (near anchor) | Remove anchor point |
| `Ctrl+drag` (on anchor) | Move anchor and both handles together (preserves local curve shape) |
| `Ctrl+Shift+drag` | Translate entire current path (all anchors and handles) |
| `Shift`+drag (on handle/anchor) | Slow drag to one-fifth speed |
| `Ctrl+Click` (near curve) | Insert anchor point on segment |
| Right-click on anchor | Toggle symmetric handles on/off |
| `c` (after placing anchor) | Toggle corner anchor on/off |
| `Tab` (hover near CPs) | Cycle highlight ring through overlapping control points |
| `f` | Toggle precision cursor mode (crosshair at 0.2× mouse speed) |
| `Enter` (precision mode) | Place point at precision crosshair |
| Arrow keys | Nudge last point / crosshair by 1 image px |
| `Shift`+Arrow | Nudge by 10 image px |
| `Ctrl+Shift`+Arrow | Nudge by 0.1 image px |
| `Shift`+left-drag | Zoom rectangle |
| Right-click drag | Pan canvas |
| Scroll wheel | Zoom in/out |
| `Ctrl+0` | Fit image to window |
| `Ctrl+Z` | Undo |
| `Ctrl+Y` / `Ctrl+Shift+Z` | Redo |
| `Ctrl+V` | Paste image from clipboard |

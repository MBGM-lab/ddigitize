# Image Loading

An image can be loaded by any of three methods:

1. **File picker.** Click **Choose file** in the toolbar (or the large drop zone shown
   when no image is loaded). Accepts PNG, JPEG, BMP, GIF, and WebP.
2. **Drag-and-drop.** Drag any image file from your file manager and drop it onto the
   canvas or the welcome drop zone.
3. **Clipboard paste.** Press `Ctrl+V` (or `Cmd+V` on macOS) to paste an image copied
   from another application or a web browser (e.g. right-click → Copy image on a
   figure in a PDF viewer or web page).

Loading a new image resets all paths but preserves the current coordinate system
calibration. The image can be shown or hidden at any time using the
**Hide Image** / **Show Image** toggle button in the toolbar without affecting paths
or calibration.
